==== WHAT IS A WEBPACK IN REACT ??

Webpack

React code jo aap likhte ho (JSX, ES6, CSS, images) browser seedha nahi samajhta.

Webpack = tool jo aapka code browser ke liye convert aur bundle karta hai.

JSX → JS

Modern JS → Older JS (taaki sab browsers me chale)

CSS & images → ek package me bundle

Basically: Webpack = code ka “translator + packer”.
